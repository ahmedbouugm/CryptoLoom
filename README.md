# CryptoLoom

Provides a command-line interface to manage Bitcoin transactions and wallet balances with encrypted data storage.

The key benefits of using CryptoLoom include:

- Provides a command-line interface to
- manage Bitcoin transactions and wallet
- balances with encrypted data storage

## Key Features

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CryptoLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
